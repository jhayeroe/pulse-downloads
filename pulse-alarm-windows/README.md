# PULSE Alarm for Windows

Windows-native companion based on the PULSE Android design.

## v1.0.0 MVP

- PULSE red/black/white dashboard
- Local alarm storage
- Full-screen, always-on-top alarm
- Snooze and hold-for-two-seconds Done
- Meeting Mode
- System tray operation
- Single-file Windows x64 build through GitHub Actions

The first release is intentionally local-first. Android-to-Windows cloud sync, recurring-day rules, custom audio, startup registration, themes, updater UI, and signed installer are scheduled for the next implementation pass.
